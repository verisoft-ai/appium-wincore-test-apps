# Oracle Forms fixture

One form, `WINCORE_FIXTURE`, for appium-wincore-java-bridge's Oracle Forms
support: plain text items, a `VTextFieldEng` PJC item (mirrors the
customer's subclass), a password item, and an `ECHO` button that writes the
values the Forms server holds into `RESULT`. Generated by
`generator/GenerateFixture.java` (JDAPI); built by `build.ps1`.

## Setup

Elevated PowerShell. Downloads go in `C:\oracle-installers`: FMW
Infrastructure 14.1.2 (`V1045135-01.zip`) and Forms 14.1.2 for Windows
(`V1045122-01.zip`) from the [Forms downloads][forms-dl] page. Docker
Desktop must be installed.

[forms-dl]: https://www.oracle.com/middleware/technologies/forms/downloads.html

```powershell
$oh = 'C:\Oracle\Middleware\Oracle_Home'
$dh = "$oh\user_projects\domains\base_domain"
```

### Oracle JDK 21

The FMW installer rejects other vendors' JDKs, and winget's
`Oracle.JDK.21` link is dead:

```powershell
$u = 'https://download.oracle.com/java/21/archive/jdk-21.0.10_windows-x64_bin.msi'
Invoke-WebRequest $u -OutFile jdk21.msi
Start-Process msiexec.exe -ArgumentList '/i', "$PWD\jdk21.msi", '/qn' -Wait
$jdk = 'C:\Program Files\Java\jdk-21.0.10'
[Environment]::SetEnvironmentVariable('JAVA_HOME', $jdk, 'Machine')
$env:JAVA_HOME = $jdk
```

### FMW Infrastructure and Forms

```powershell
cd C:\oracle-installers
Expand-Archive V1045135-01.zip . -Force
Expand-Archive V1045122-01.zip . -Force
$rsp = "[ENGINE]`nResponse File Version=1.0.0.0.0`n[GENERIC]",
  "ORACLE_HOME=$oh", 'DECLINE_SECURITY_UPDATES=true',
  'SECURITY_UPDATES_VIA_MYORACLESUPPORT=false'
$rsp + 'INSTALL_TYPE=Fusion Middleware Infrastructure' | Set-Content infra.rsp
$rsp + 'INSTALL_TYPE=Forms and Reports Deployment' | Set-Content forms.rsp
& "$env:JAVA_HOME\bin\java" -jar fmw_14.1.2.0.0_infrastructure.jar `
  -silent -responseFile "$PWD\infra.rsp"
.\setup_fmw_14.1.2.0.0_fr_win64.exe -silent `
  -responseFile "$PWD\forms.rsp" -jreLoc $env:JAVA_HOME
```

### Database (Docker, 23.9)

RCU 14.1.2 rejects Database 26ai (23.26) without a support-only patch, so
the repository runs on 23.9, on port 1522:

```powershell
$pw = Read-Host 'SYS password'
docker run -d --name wincore-oracle-db --restart unless-stopped `
  -p 1522:1521 -v wincore-oracle-db:/opt/oracle/oradata `
  -e ORACLE_PASSWORD=$pw gvenzl/oracle-free:23.9
```

Wait for `DATABASE IS READY TO USE` in `docker logs wincore-oracle-db`.

### Schemas and domain

RCU prompts for the SYS password, then a new schema password:

```powershell
& "$oh\oracle_common\bin\rcu.bat" -silent -createRepository `
  -databaseType ORACLE -connectString localhost:1522/FREEPDB1 `
  -dbUser sys -dbRole sysdba -schemaPrefix DEV `
  -useSamePasswordForAllSchemaUsers true -component STB -component OPSS `
  -component IAU -component IAU_APPEND -component IAU_VIEWER `
  -component MDS -component WLS -component UCSUMS
& "$oh\oracle_common\common\bin\config.cmd"
```

In the wizard: new domain at `$dh`, template **Oracle Forms**, admin user
`weblogic`, mode **Development** (the others disable plain HTTP), RCU data
`localhost` / `FREEPDB1` / `1522` / `DEV_STB`.

### Domain fixes

The 14.1.2 wizard creates the Forms instance at `components\FORMS\forms1`
but points `default.env` at `components\FORMS\instances\forms1`, and the
Forms runtime can't find its key binding file. Without these, the launcher
fails with FRM-93131 (`basesaa.txt`), then "Error opening Oracle*Terminal
file fmrweb":

```powershell
$forms = "$dh\config\fmwconfig\components\FORMS"
New-Item -ItemType Directory -Force "$forms\instances" | Out-Null
New-Item -ItemType Junction -Path "$forms\instances\forms1" `
  -Target "$forms\forms1"
$cfg = "$dh\config\fmwconfig\servers\WLS_FORMS\applications\" +
  'formsapp_14.1.2\config\formsweb.cfg'
(Get-Content $cfg) -replace '^term=.*',
  "term=$oh\forms\templates\resource\fmrweb.res" | Set-Content $cfg
```

### Environment and server credentials

```powershell
[Environment]::SetEnvironmentVariable('ORACLE_HOME', $oh, 'Machine')
[Environment]::SetEnvironmentVariable('DOMAIN_HOME', $dh, 'Machine')
$c = Get-Credential -UserName weblogic -Message 'WebLogic admin'
'AdminServer', 'WLS_FORMS' | ForEach-Object {
  $d = New-Item -ItemType Directory -Force "$dh\servers\$_\security"
  "username=weblogic`npassword=$($c.GetNetworkCredential().Password)" |
    Set-Content "$d\boot.properties" -Encoding ASCII }
```
